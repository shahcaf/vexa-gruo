🛡️ Modmail Staff Dashboard

Here are the available staff commands to manage support tickets:

⚙️ Server Setup

  • /setup — Configure category, log channel, mod role & language.
  • /settings — View active server modmail configuration.
  • /language — Change the server modmail language.

🔒 Ticket Control

  • /close [reason] [silent] — Mark ticket resolved, archive transcript, and delete channel.

💬 Staff Replies

  • /reply <message> [anonymous] — Relay staff response to user DM.
    (Or type directly in modmail channel)

👥 Thread Access

  • /add <user> — Grant extra staff/user access to thread.
  • /remove <user> — Revoke access from thread.

⛔ User Blocklist

  • /block <user> [reason] — Prevent user from opening tickets.
  • /unblock <user> — Restore ticket creation access.
